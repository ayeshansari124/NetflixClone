# 🎬 NextFlix - Netflix UI Clone

A modern Netflix-inspired streaming platform interface built using **Next.js, React, TypeScript, and Tailwind CSS**.

Originally developed as a basic HTML/CSS clone, NextFlix was later rebuilt using a modern React architecture focused on responsiveness, reusable components, and scalable frontend structure.

## 🌐 Live Demo

https://netflix-clone-cyan-xi-71.vercel.app/

---

## ✨ Features

- Netflix-inspired landing page
- Responsive dark-themed interface
- Trending content section
- Interactive FAQ accordion
- Reusable React components
- Optimized frontend architecture
- Smooth responsive layout

---

## 🚀 Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- React Icons
